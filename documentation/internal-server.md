# MonoFS Internal Server — Function Documentation

## `/internal/server/cfg_backend.go`

---

### `SetCfgStore`
```go
func (s *Server) SetCfgStore(store CfgBackendStore)
```
Wires a `CfgBackendStore` into the server. Must be called before serving requests if any repository uses the `"cfg"` storage backend. Stores the reference in `s.cfgStore`.

---

### `usesCfgBackend`
```go
func (info repoInfo) usesCfgBackend() bool
```
Reports whether the repository's `StorageBackend` field, after normalization, equals `"cfg"`. Used as a predicate to decide if path resolution should route through the cfg backend.

---

### `resolveCfgPath`
```go
func (s *Server) resolveCfgPath(ctx context.Context, storageID, filePath string) (*kvsResolvedPath, bool, error)
```
Resolves a logical path within a cfg-backed repository. It:
1. Looks up the repo by `storageID` and checks `usesCfgBackend()`.
2. Returns `(nil, false, nil)` if the repo doesn't use cfg.
3. Returns an error if `s.cfgStore` is nil.
4. Calls `s.cfgStore.Stat()` — if the path exists as a file, returns a `kvsResolvedPath` with `isDir=false`.
5. Falls back to `s.cfgStore.ListDir()` — if entries exist, returns `isDir=true`.

**Return values:** `(resolved, handled, err)` — `handled=true` means the path belongs to this backend (whether found or not-found). `handled=false` means the repo is not cfg-backed.

---

### `ingestCfgFiles`
```go
func (s *Server) ingestCfgFiles(ctx context.Context, displayPath string, files []*pb.FileMetadata) (int64, int64, error)
```
Handles `IngestFileBatch` for cfg-backed repositories. Ingestion protocol:
- Each file's path must be of the form `{sha}/{relative-file-path}`.
- Files with the same SHA are grouped and pushed as one version via `PushVersion`.
- A file with `BackendMetadata["cfg_set_current"] == "true"` triggers `SetCurrent` for its SHA after `PushVersion` succeeds.
- Files with `BackendMetadata["dir_hint"] == "true"` or `BackendMetadata["file_type"] == "1"` (directories) are skipped.

**Returns:** `(filesIngested, filesFailed, error)`. Returns the number of files successfully pushed and the number that failed.

---

### `cfgProductFromDisplayPath`
```go
func cfgProductFromDisplayPath(displayPath string) string
```
Extracts the product name from a display path. The product is the last non-empty path component.  
Example: `"/cfg/my-app"` → `"my-app"`.

---

### `splitSHAFromPath`
```go
func splitSHAFromPath(path string) (sha, relPath string, ok bool)
```
Splits a path of the form `{sha}/{relative...}` into its SHA prefix and the remainder. Returns `ok=false` if the path has no `"/"` separator.

---

### `cfgMode`
```go
func cfgMode(isDir bool) uint32
```
Returns POSIX mode bits for a cfg entry: `0755 | S_IFDIR` for directories, `0644 | S_IFREG` for files.

## `/internal/server/directory.go`

---

### `inferDirectoryMode`
```go
func inferDirectoryMode(mode uint32) uint32
```
Infers a directory mode from a file mode. If the file mode has no write bits (`0222`), returns `0555 | S_IFDIR` (read-only). Otherwise returns `0755 | S_IFDIR`.

---

### `normalizeExplicitDirectoryMode`
```go
func normalizeExplicitDirectoryMode(mode uint32) uint32
```
Normalizes a mode for an explicitly created directory. Extracts the permission bits (`0777`), defaults to `inferDirectoryMode` if permissions are zero, then ORs with `S_IFDIR`.

---

### `upsertDirectoryMetadata`
```go
func (s *Server) upsertDirectoryMetadata(tx *nutsdb.Tx, storageID, dirPath string, mode uint32, mtime int64, explicit bool) error
```
Inserts or updates canonical directory metadata in `bucketDirMeta`. If an existing entry is found (unmarshaled from JSON), it preserves existing `Path` and `Mtime` (keeping the latest), propagates `Explicit` flags, and merges mode. The key is generated by `makeDirMetaKey(storageID, dirPath)`.

---

### `upsertDirectoryHierarchy`
```go
func (s *Server) upsertDirectoryHierarchy(tx *nutsdb.Tx, storageID, filePath string, mode uint32, mtime int64, explicitLeafDir bool) error
```
Walks the directory hierarchy of `filePath` from root downward, calling `upsertDirectoryMetadata` for each ancestor directory. If `explicitLeafDir` is true, the last component of the path is also treated as a directory (not just intermediate ancestors).

---

### `getDirectoryMetadataTx`
```go
func (s *Server) getDirectoryMetadataTx(tx *nutsdb.Tx, storageID, dirPath string) (*dirMetadata, error)
```
Looks up and unmarshals a `dirMetadata` from `bucketDirMeta` within an existing transaction. Returns `nil, error` if not found or unmarshal fails.

---

### `lookupCanonicalDirectory`
```go
func (s *Server) lookupCanonicalDirectory(storageID, dirPath string) *pb.LookupResponse
```
Looks up a directory from the canonical directory metadata (`bucketDirMeta`). Opens a read-only NutsDB view transaction, calls `getDirectoryMetadataTx`, and if found returns a `LookupResponse` with `Ino` computed by `hashPath`, mode, size=0, and mtime. Returns `nil` if not found or if `dirPath` is empty.

---

### `directChildName`
```go
func directChildName(parentDir, candidate string) (string, bool)
```
Extracts the direct child name of `candidate` relative to `parentDir`. For example:  
`directChildName("foo", "foo/bar/baz")` → `("bar", true)`  
`directChildName("", "foo/bar/baz")` → `("foo", true)`  
Returns `("", false)` if `candidate` is not under `parentDir`.

---

### `storeDirectoryIndex`
```go
func storeDirectoryIndex(tx *nutsdb.Tx, storageID, dirPath string, entries []dirIndexEntry) error
```
Sorts entries by name, marshals to JSON, and stores in `bucketDirIndex` using `makeDirIndexKey(storageID, dirPath)`.

---

### `normalizeSummaryEntry`
```go
func normalizeSummaryEntry(entry dirIndexEntry) dirIndexEntry
```
Normalizes a dir index entry for summary storage. Directories get size=0, hashKey cleared, and mode normalized via `normalizeExplicitDirectoryMode`. Files get mode stripped to permission bits only (`& 0777`).

---

### `storeDirectorySummary`
```go
func storeDirectorySummary(tx *nutsdb.Tx, storageID, dirPath string, entries []dirIndexEntry) error
```
Normalizes all entries via `normalizeSummaryEntry`, sorts by name, marshals to JSON, and stores in `bucketDirSummary` using `makeDirMetaKey(storageID, dirPath)`.

---

### `loadDirectorySummaryTx`
```go
func (s *Server) loadDirectorySummaryTx(tx *nutsdb.Tx, storageID, dirPath string) ([]dirIndexEntry, error)
```
Loads and unmarshals directory summary entries from `bucketDirSummary` within an existing transaction.

---

### `isDirSummaryMissingOrCorrupt`
```go
func isDirSummaryMissingOrCorrupt(err error) bool
```
Returns `true` if the error means the dir summary entry doesn't exist or is unreadable due to an MMap/segment-rotation issue (e.g., `EBADF`). In these cases the caller should treat the summary as empty and rebuild it.

---

### `upsertDirectorySummaryEntry`
```go
func (s *Server) upsertDirectorySummaryEntry(tx *nutsdb.Tx, storageID, dirPath string, entry dirIndexEntry) error
```
Inserts or updates a single entry in a directory's summary. Normalizes the entry first, loads existing entries, replaces or appends, then calls `storeDirectorySummary`.

---

### `removeFromDirectorySummary`
```go
func (s *Server) removeFromDirectorySummary(tx *nutsdb.Tx, storageID, parentDir, entryName string) error
```
Removes an entry by name from a parent directory's summary. If no entries remain after filtering, deletes the summary key entirely.

---

### `upsertPathIntoDirectorySummary`
```go
func (s *Server) upsertPathIntoDirectorySummary(tx *nutsdb.Tx, storageID, filePath string, mode uint32, size uint64, mtime int64, explicitLeafDir bool, hashKey string) error
```
Walks all path components of `filePath` and upserts each as an entry into the respective parent directory's summary. Intermediate components are marked as directories; leaf components are directories if `explicitLeafDir` is true.

---

### `buildDirectoryEntriesFromCanonical`
```go
func (s *Server) buildDirectoryEntriesFromCanonical(tx *nutsdb.Tx, storageID, dirPath string) ([]dirIndexEntry, bool, error)
```
Rebuilds a complete directory entry list from canonical sources: the dir summary (`bucketDirSummary`), path index (`bucketPathIndex`) for files, and dir metadata (`bucketDirMeta`) for explicit directories. Returns the sorted entries, whether the directory exists, and any error.

---

### `rebuildDirectoryIndexFromCanonical`
```go
func (s *Server) rebuildDirectoryIndexFromCanonical(storageID, dirPath string) ([]dirIndexEntry, bool, error)
```
Wraps `buildDirectoryEntriesFromCanonical` in an update transaction and stores both the summary and the index. Used as a fallback when the directory index is missing or corrupt.

---

### `lookupDirectorySummaryFile`
```go
func (s *Server) lookupDirectorySummaryFile(storageID, filePath string) *pb.LookupResponse
```
Looks up a file in its parent's directory summary. Extracts the parent directory and entry name, loads the summary, finds a non-directory entry with matching name, and returns a `LookupResponse`.

---

### `pruneImplicitDirectories`
```go
func (s *Server) pruneImplicitDirectories(tx *nutsdb.Tx, storageID, startDir string) error
```
Walks upward from `startDir`, deleting implicit (non-explicit) directory entries that have no children. Stops when it reaches an explicit directory or a directory with remaining children. Deletes from `bucketDirMeta`, `bucketDirSummary`, `bucketDirIndex`, and removes entries from parent directory indexes and summaries.

---

### `updateDirectoryIndexHierarchy`
```go
func (s *Server) updateDirectoryIndexHierarchy(tx *nutsdb.Tx, storageID, filePath string, fileHashKey []byte, mode uint32, size uint64, mtime int64, explicitLeafDir bool) error
```
Hybrid approach for incremental directory index updates during single-file operations. Updates all parent directories in the path hierarchy by:
1. Calling `upsertDirectoryHierarchy` for canonical dir metadata.
2. Calling `upsertPathIntoDirectorySummary` for canonical summaries.
3. Directly updating the `bucketDirIndex` entries for each parent directory.

**Not used during batch operations** — `BuildDirectoryIndexes` handles those for performance.

---

### `checkVirtualDirectory`
```go
func (s *Server) checkVirtualDirectory(storageID, dirPath string) *pb.LookupResponse
```
Checks if a path exists as a virtual directory in the directory index. Looks up the parent directory's index in `bucketDirIndex` and searches for the entry name. Used as a fallback when a directory has no explicit metadata entry but is referenced in its parent's index.

---

### `checkVirtualFile`
```go
func (s *Server) checkVirtualFile(storageID, filePath string) *pb.LookupResponse
```
Same pattern as `checkVirtualDirectory` but for files. Checks if a file is listed in its parent's directory index even when metadata may be absent (e.g., after overlay cleanup before full metadata ingestion).

---

### `ReadDir`
```go
func (s *Server) ReadDir(req *pb.ReadDirRequest, stream grpc.ServerStreamingServer[pb.DirEntry]) error
```
Implements the `ReadDir` RPC (streaming). Handles three cases:
1. **Root directory (`path==""`):** Lists all top-level directories from repos and managed namespaces.
2. **Intermediate directory (no matching repo):** Lists subdirectories by prefix-scanning registered repos.
3. **Within a repo:** Loads from `bucketDirIndex`; falls back to `rebuildDirectoryIndexFromCanonical`; if still not found, attempts forwarding to the HRW target node (primary → backups).

KVS and cfg backends are handled via `resolveKVSPath`/`resolveCfgPath` before the normal path.

---

### `forwardableTarget`
```go
func (s *Server) forwardableTarget(path string) *sharding.Node
```
Tries to find a node that should own OCI-registry data under `path`. Iterates path prefixes from longest to shortest (minimum 2 segments), generates candidate storage IDs via `sharding.GenerateStorageID`, and uses HRW to find a healthy non-self target. Returns `nil` if no suitable target is found.

---

### `BuildDirectoryIndexes`
```go
func (s *Server) BuildDirectoryIndexes(ctx context.Context, req *pb.BuildDirectoryIndexesRequest) (*pb.BuildDirectoryIndexesResponse, error)
```
Implements the `BuildDirectoryIndexes` RPC. Called after batch ingestion completes. Scans all owned files for the given `storageID`, builds an in-memory `dirPath → []dirIndexEntry` map by walking each file's path hierarchy, then writes all directory indexes, summaries, and canonical metadata to the database in a single transaction. Merges with existing entries to preserve data from dir-hint batches sent by other nodes.

---

### `removeFromDirectoryIndex`
```go
func (s *Server) removeFromDirectoryIndex(tx *nutsdb.Tx, storageID, parentDir, entryName string) error
```
Removes a single file or subdirectory entry from a parent directory's index. Loads the index, filters out the entry, and stores back. Deletes the entire index entry if the directory becomes empty.

---

### `DeleteDirectoryRecursive`
```go
func (s *Server) DeleteDirectoryRecursive(ctx context.Context, req *pb.DeleteDirectoryRecursiveRequest) (*pb.DeleteDirectoryRecursiveResponse, error)
```
Implements the `DeleteDirectoryRecursive` RPC. Removes a directory and all its contents:
- For KVS-backed repos, delegates to `deleteKVSDirectory`.
- For Git-backed repos: walks the directory index tree in a read-only pass to collect all file and directory paths, then deletes them from `bucketMetadata`, `bucketPathIndex`, `bucketOwnedFiles`, `bucketReplicaFiles`, `bucketDirMeta`, `bucketDirSummary`, and `bucketDirIndex` in a single update transaction. Removes the target directory from its parent's index and prunes implicit ancestors.

## `/internal/server/fs.go`

---

### `Lookup`
```go
func (s *Server) Lookup(ctx context.Context, req *pb.LookupRequest) (*pb.LookupResponse, error)
```
Implements the `Lookup` RPC. Resolution order:
1. Root → returns root directory attrs.
2. Managed namespace paths (`doctor`, `doctor/v1`) → returns directory attrs.
3. Full repo display path → returns directory attrs.
4. Intermediate directory (cached) → returns directory attrs.
5. Resolves to `(storageID, filePath)`. If the filePath is empty, returns repo-root directory attrs.
6. Checks `resolveKVSPath` and `resolveCfgPath` for backend-routed paths.
7. Looks up metadata in `bucketMetadata` via hash key from path index.
8. Falls back to `lookupCanonicalDirectory` → `lookupDirectorySummaryFile` → `checkVirtualDirectory` → `checkVirtualFile` → `checkFailoverCache`.
9. If still not found and forwarding is enabled, tries primary node, then backups.
10. Returns `{Found: false}` if nothing matches.

---

### `GetAttr`
```go
func (s *Server) GetAttr(ctx context.Context, req *pb.GetAttrRequest) (*pb.GetAttrResponse, error)
```
Implements the `GetAttr` RPC. Same resolution order as `Lookup` but returns a full `GetAttrResponse` with inode, mode, size, mtime, atime, ctime, nlink, uid, and gid. Directories get `nlink=2`; files get `nlink=1`.

---

### `Read`
```go
func (s *Server) Read(req *pb.ReadRequest, stream grpc.ServerStreamingServer[pb.DataChunk]) error
```
Implements the `Read` RPC (streaming). Handles:
- **KVS backend:** Reads file content via `kvsStore.ReadFile`, applies offset/size slicing, streams in 64KB chunks.
- **Cfg backend:** Reads via `cfgStore.ReadFile`, same streaming pattern.
- **Git backend:** Looks up metadata → blob hash. Skips empty blobs (SHA-256 of empty content). Reads via `readViaFetcher`. Handles failover cache fallback and HRW forwarding (primary → backups). Records access for the predictor asynchronously. Streams content in 64KB chunks.

### `DeleteFile`
```go

```
Removes a file's metadata after rebalancing (called by the router). For KVS backend, delegates to `deleteKVSFile`. ### `DeleteRepository`
```go
func (s *Server) DeleteRepository(ctx context.Context, req *pb.DeleteRepositoryOnNodeRequest) (*pb.DeleteRepositoryOnNodeResponse, error)
```
Removes all data for a repository from this node. Steps:
1. Deletes KVS-backed contents.
2. Deletes repo info from `bucketRepos`.
3. Deletes display-path → storageID mapping from `bucketRepoLookup`.
4. Deletes onboarding status.
5. Scans and deletes all owned files (metadata + ownership + path index), tracking deleted bytes.
6. Deletes all replica files.
7. Deletes all canonical directory metadata, summaries, and directory indexes.
8. Updates counters and clears intermediate directory cache.

### `RecordAccess`

Records a file access and triggers prediction. Skips ignored client IDs. Records in three subsystems:

### `Predict`
```go
func (p *Predictor) Predict(storageID, filePath string) []PredictedFile
```
Returns predicted files based on access patterns. Combines three prediction sources:
1. **Markov chain predictions** (`predictMarkov`) — based on file transition probability.
2. **Directory-based predictions** (`predictDirectory`) — based on access frequency within the same directory.
3. **Structural predictions** (`predictStructural`) — heuristic patterns like README.md and go.mod/go.sum for `.go` files.
Merges, deduplicates (keeping highest probability), filters by `PrefetchThreshold`, and limits to `MaxPrefetchFiles`.

---

### `predictMarkov`
```go

```
Generates predictions from the Markov chain for a given storageID. Calculates transition probabilities from the source file. If `MarkovDepth > 1`, recurses one level deeper (second-order predictions) with a 0.7 discount factor.

### `predictDirectory`
```go

```
Generates predictions from directory access patterns. Requires at least 5 total accesses to the directory. Returns files whose access ratio exceeds `DirectoryThreshold`, scaled by 0.6 (weaker signal than Markov).

### `predictStructural`

Generates heuristic predictions based on file extension and common patterns:
- `.go` files → `go.mod` (0.4), `go.sum` (0.3)

Merges predictions from multiple sources. Deduplicates by `"storageID:filePath"`, keeping the highest probability. Returns results sorted by probability descending.
